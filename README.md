# Pizza-Project-Business 

README: 
Pizza Project 

What is this?
A Python script for a simple pizza ordering system. It handles menu selection, calculates prices, and prints a receipt.

How to use it:
Make sure you have Python installed.

Open your terminal or VS Code.

Run the script: python pizza-project-code.py

Follow the prompts to build your pizza.

Input Checks: 
The program won't crash if you type letters instead of numbers.

Math Check: 
Verified that prices and taxes calculate correctly every time.
